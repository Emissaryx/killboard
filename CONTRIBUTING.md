# Contributing

This repository is an Emissary integration fork of `dalen/killboard`. Keep changes reviewable and easy to return upstream.

1. Read `EMISSARY_CONTRIBUTIONS.md` before preparing work for Dalen or the Return of Reckoning team.
2. Create focused upstream contributions from `upstream/main` on a `contrib/<feature>` branch.
3. Do not mix formatting, dependency, navigation, or unrelated feature changes into the same contribution.
4. Run `npm ci`, `npm test`, and `npm run codegen:check` before opening a pull request.
5. Describe the affected routes, API queries, screenshots or reproduction steps, and verification results.
6. Never commit credentials, tokens, private player information, or unpublished Return of Reckoning data.

Do not add Dalen, Max Hayman, or other Return of Reckoning developers as collaborators unless they explicitly request it. Share a branch or pull-request link instead.
