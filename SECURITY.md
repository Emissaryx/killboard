# Security Policy

## Supported versions

Security fixes are applied to the latest code on the default branch.

## Reporting a vulnerability

Please do not open a public issue for a suspected vulnerability.

Use GitHub's private vulnerability reporting feature on this repository when it is available. If that option is not shown, contact the repository owner privately through the GitHub profile at https://github.com/Emissaryx and include:

1. A clear description of the issue.
2. Steps to reproduce it.
3. The affected page, endpoint, or commit.
4. The potential impact.
5. Any suggested mitigation.

Please allow reasonable time to investigate before publicly disclosing the issue. Never include credentials, access tokens, personal data, or other secrets in a report.
